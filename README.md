# Students Performance Data Analysis

## About the Project

This project performs Exploratory Data Analysis (EDA) on the Students Performance dataset using Python.

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Dataset

The dataset contains information about students' gender, race/ethnicity, parental education, lunch type, test preparation course, and math, reading, and writing scores.

## Analysis Performed

* Identified categorical and numerical columns
* Checked missing values and duplicate records
* Calculated mean, median, and mode
* Identified outliers using the IQR method
* Created histograms, bar charts, and box plots
* Compared average scores by gender and test preparation course
* Examined correlations between subject scores

## Conclusion

This project helped me understand data cleaning, statistical analysis, outlier detection, and data visualization using Python.
